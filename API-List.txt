====================================================
FLASHKART BACKEND API COLLECTION
====================================================

Base URL
------------------------------------
http://localhost:5000/api

====================================================
1. USER REGISTER
====================================================

Method:
POST

URL:
/users/register

Headers:
Content-Type: application/json

Body:

{
    "name": "Admin",
    "email": "admin@gmail.com",
    "password": "123456"
}

Expected:
201 Created


====================================================
2. USER LOGIN
====================================================

Method:
POST

URL:
/users/login

Headers:
Content-Type: application/json

Body:

{
    "email": "admin@gmail.com",
    "password": "123456"
}

Response:

{
    "message": "Login Successful",
    "token": "YOUR_JWT_TOKEN"
}

Copy this JWT Token.

====================================================
3. PROTECTED ROUTE
====================================================

Method:
GET

URL:
/users/profile

Headers:

Authorization: Bearer YOUR_JWT_TOKEN

Expected:
200 OK


====================================================
4. CREATE PRODUCT
====================================================

Method:
POST

URL:
/products

Headers:

Authorization: Bearer YOUR_JWT_TOKEN

Content-Type: application/json

Body:

{
    "name": "iPhone 16 Pro",
    "description": "Apple flagship phone",
    "price": 120000,
    "stock": 50,
    "reservedStock": 0,
    "isActive": true
}

Expected:
201 Created


====================================================
5. CREATE PRODUCT VALIDATION
====================================================

Method:
POST

URL:
/products

Headers:

Authorization: Bearer YOUR_JWT_TOKEN

Body:

{
    "name": "",
    "price": -100,
    "stock": -5
}

Expected:

400 Bad Request


====================================================
6. GET ALL PRODUCTS
====================================================

Method:

URL:

No Header Required

7. GET PRODUCT BY ID
====================================================

GET

URL:

/products/PRODUCT_ID

/products/2e2a88e2-5c7d-4d6b-b1fd-xxxxxxxx

Expected:
200 OK
